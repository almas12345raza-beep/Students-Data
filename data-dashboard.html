This dashboard reads directly from a published Google Sheet, so it always shows what's currently in the sheet — no re-uploading needed.

  1. In Google Sheets: File → Share → Publish to web
  2. Choose the sheet/tab, set format to Comma-separated values (.csv), click Publish
  3. Copy the generated link
  4. Open this file in a text editor, find SHEET_CSV_URL near the top of the script, and paste the link between the quotes
  5. Save and reopen this file — it will load automatically from then on
